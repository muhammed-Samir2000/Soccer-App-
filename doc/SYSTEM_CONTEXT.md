# System Context

## Product Summary
- Mobile MVP for booking football playgrounds.
- Primary goal is to validate the booking experience with real users.

## User Roles
- `Player`: browses slots, creates bookings, and selects optional services.
- `Admin`: manages bookings and oversees playground availability.

## MVP Scope
- Focus only on the core booking flow.
- Includes browsing available slots, selecting a slot, adding optional services, and confirming a booking.

## Business Rules
- Ball is included by default in every booking.
- Optional services are limited to:
  - Drinks
  - Photography
  - Referee

## Tech Stack
- Flutter
- Dart
- Supabase (later)

## Explicit Exclusions
- No WhatsApp integration
- No push notifications
- No advanced payments

## Goal
- Build a working MVP to validate the booking experience.
