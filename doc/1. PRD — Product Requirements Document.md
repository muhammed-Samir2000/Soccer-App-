📄 1. Product Requirements Document (PRD)
📌 Product Name

Playground Booking Mobile App

🎯 Objective

Build a mobile application that enables users to:

View available football field slots
Book and pay for reservations
Add optional services (drinks, photography, referee)
Receive notifications about empty slots and offers

And enables administrators to:

Manage bookings and schedules
Monitor payments
Manage services and pricing
Increase utilization through automated notifications
👥 Target Users
1. Players (Customers)
Book fields
Pay for reservations
Receive notifications
2. Playground Management (Admins)
Manage bookings
Control pricing and availability
Monitor operations
🚀 Core Value Proposition
Reduce manual booking operations
Increase field utilization
Automate communication (notifications & WhatsApp later)
Provide seamless mobile booking experience
📱 Platform
Mobile App (React Native – Android first, iOS later)
🧩 Core Features
Player Features
User registration & login
View available time slots
Book a slot
Online payment / upload payment proof
Booking confirmation
Add optional services:
Drinks
Photography
Referee
Receive notifications:
Booking confirmation
Match reminders
Daily empty slots
Offers
Admin Features
Dashboard overview
Manage bookings
Approve/reject payments
Manage time slots
Manage pricing
Manage optional services
Send notifications
View reports
⚙️ Booking Logic
Ball is included by default (not optional)
Slots can be:
Available
Held (temporary)
Booked
Booking expires if not paid within a defined time
🔔 Notifications System
Daily empty slots notification
Last-minute availability alerts
Booking reminders
Promotional offers
💰 Monetization
Field booking fees
Additional services revenue
