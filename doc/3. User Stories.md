📄 3. User Stories
🎮 Player User Stories
•	As a player, I want to view available slots so I can choose a suitable time
•	As a player, I want to book a slot so I can reserve the field
•	As a player, I want to pay for my booking so it gets confirmed
•	As a player, I want to add optional services so I can enhance my experience
•	As a player, I want to receive reminders so I don’t miss my match
•	As a player, I want to receive notifications about empty slots so I can book quickly
•	As a player, I want to see my booking history

🧑‍💼 Admin User Stories
•	As an admin, I want to view all bookings so I can manage operations
•	As an admin, I want to approve payments so bookings become confirmed
•	As an admin, I want to manage available slots
•	As an admin, I want to create offers to increase bookings
•	As an admin, I want to see reports to understand performance
•	As an admin, I want to manage services offered
